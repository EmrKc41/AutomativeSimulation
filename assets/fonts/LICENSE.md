These files are committed to the repository because the PDF report embeds them.
PDFKit's built-in fonts use WinAnsi encoding, which has no `ş`, `ğ`, `İ` or `ı`
— a Turkish shift report rendered with them comes out mangled. Fira Sans is
also the typeface the command centre uses, so the report and the screen match.
